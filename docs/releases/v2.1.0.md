# PocketPad — your phone, your controller

**Made by Sanjay.** The first GitHub release brings together **PocketPad Desktop 2.1** for Windows and **PocketPad Android 1.2**.

Turn your Android phone into a customizable PC gamepad: arrange your HUD in the native desktop studio, pair over your local network using a QR code, and play with Xbox/XInput or PlayStation/DS4 output.

## Downloads

| File | Use it for |
| --- | --- |
| **PocketPad-Setup.exe** | Recommended Windows installation, with shortcuts and an uninstaller. |
| **PocketPad-Android.apk** | Install or update the Android companion. |
| **PocketPad-Portable.zip** | Extract the complete Windows app and run `PocketPad.exe` without app installation. |
| **SHA256SUMS.txt** | Verify downloaded files with SHA-256. |

The setup and portable downloads include the Python runtime, libraries, Android APK and signed ViGEmBus driver installer. Install ViGEmBus through the app if Windows gamepad output is unavailable. The Android APK uses the same signing identity as the previous local build, so an update preserves preferences.

## Inside this release

- **Custom controller studio:** Xbox and PS5-style factory layouts, two custom slots, a drag-and-drop control library, per-control resizing and JSON import/export.
- **Gyro for aiming and driving:** quick on/off, GTA V aiming mapped to the right stick, LT/L2-only activation, tilt steering, sensitivity, invert axes and recenter. Gyro is off on fresh installs.
- **PS-style touchpad:** two independent touch contacts plus click with DS4 output, or mouse input with Xbox output.
- **Dark themes and animation:** matte black, OLED black and translucent themes, animated launch/connection states, rich transitions and optional phone haptics. UI animations are on by default and have their own off switch.
- **Easier pairing:** native Android QR scanning, a dedicated mobile download page on PC, manual links and offline preview.
- **Guided first use:** interactive pairing, resizing, touchpad and gyro practice without sending practice input to a game.
- **Sanjay's app:** creator credit in the README, Windows Preferences, Android home and Windows publisher information.

## First launch

1. Install the Windows app and the Android APK.
2. Open PocketPad on the PC; install the virtual controller driver if prompted.
3. Put both devices on the same Wi-Fi/hotspot or tethered network.
4. Open **Connect phone** on the PC and scan its pairing QR from the Android app.
5. Pick your layout, tap **Start controller**, then start your game.

For aiming, choose **Gyro settings → GTA V aiming**, switch **Gyro on**, and hold **LT / L2** while moving the phone. Tune sensitivity to your preference. The right stick remains available for larger turns.

## Compatibility and validation

Requires Windows 10/11 x64 with .NET Framework 4.8; Android 8.0+ for the companion. The PS5 layout uses a virtual DS4 device, with no native DualSense adaptive triggers or game rumble. Bluetooth is available through tethering/PAN when supported; direct Bluetooth HID/BLE pairing is not implemented.

Builds, APK signing/content checks, controller input checks and isolated install/update/uninstall have passed. Actual GTA V gameplay, physical gyro direction and feel, camera scanning and Bluetooth PAN still need checks on real devices. Personal layouts and signing keys are excluded from public uploads.
